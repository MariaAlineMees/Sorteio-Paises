
## 📌 Sobre o projeto  
O **Sorteio de Países** é uma aplicação que permite sortear países aleatoriamente a partir de uma lista pré-definida. Pode ser utilizado para brincadeiras, atividades educacionais ou qualquer outro propósito que envolva seleção aleatória de países.
